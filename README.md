# Featherbound

A private family library that turns books we love into softer, kid-appropriate editions, keeping the full story, characters and themes intact.

- **Product requirements:** [docs/PRD.md](docs/PRD.md)
- **Clickable prototype:** [prototype/](prototype/)

## Running the prototype

```bash
npm --prefix prototype install
npm --prefix prototype run dev
```

Then open http://localhost:5173. The prototype uses sample data and runs entirely in the browser; nothing is saved to a server. Sample book text comes from the public-domain *Wonderful Wizard of Oz*.
